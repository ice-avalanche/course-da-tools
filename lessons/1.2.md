# Формулы и их поведение

## Цели и требования

На занятии 1.1 критерии надежности применялись к книге в целом. Здесь они применяются к отдельным формулам. Формула считается надежной, если она:

1. дает верный результат на текущих данных;
2. остается верной при изменении значений и размера данных;
3. понятна человеку, который ее не писал.

После занятия нужно уметь:

- искать значения функцией ПРОСМОТРX и правильно обрабатывать отсутствие совпадения;
- считать суммы, количества и средневзвешенные величины с условиями через СУММПРОИЗВ;
- использовать динамические массивы (УНИК, ФИЛЬТР) и ссылаться на них оператором `#`;
- сокращать формулы и повторные вычисления функцией LET;
- объяснять, как Excel пересчитывает книгу, и находить волатильные функции.

> [!NOTE]
> Требуется Microsoft Excel 2021 или Microsoft 365 для Windows. В Excel 2016 и 2019 функций ПРОСМОТРX, LET и динамических массивов нет. Учебный файл `lesson-1.2.xlsx` содержит листы «Справочники» (номенклатура из 12 товаров, 8 торговых точек, шкала скидок), «Продажи» (реестр из 120 строк за I квартал 2026 г.), «Матрица» (выручка по точкам и месяцам), «Задания» (12 заданий с контролем) и «Пересчет» (учебные опыты).

## 1. Связь с занятием 1.1

Принципы архитектуры книги переносятся на формулы:

- **Единственный источник.** Формула ссылается на параметр и не повторяет изменяемое число.
- **Структурированные таблицы.** Формулы должны корректно работать при изменении объема данных.
- **Проверяемость.** Промежуточные шаги сложного расчета можно просмотреть и проверить.
- **Видимость ошибок.** Обрабатывается только ожидаемое состояние, остальные ошибки не скрываются.

> [!WARNING]
> Формула может быть записана верно и возвращать число, но оставаться ненадежной: зависеть от положения столбца, молча выбирать неверное совпадение, скрывать отсутствие данных или замедлять пересчет книги.

## 2. ПРОСМОТРX: основные режимы

ПРОСМОТРX ищет значение в одном массиве и возвращает соответствующее значение из другого массива.

```formula
=ПРОСМОТРX(
    искомое;
    просматриваемый_массив;
    возвращаемый_массив;
    [если_не_найдено];
    [режим_сопоставления];
    [режим_поиска]
)
```

Обязательны первые три аргумента.

### Отличия от ВПР

| Свойство | ВПР | ПРОСМОТРX |
|---|---|---|
| Где ищет | Только в первом столбце диапазона | В любом отдельном массиве |
| Куда возвращает | Только вправо, по номеру столбца | Из любого отдельного массива |
| Режим по умолчанию | Приближенный (если не указан четвертый аргумент) | Точный |
| Ссылка на результат | Номер столбца, который сдвигается при изменении структуры | Диапазон, который сдвигается вместе с данными |

Два последних отличия важнее остальных. Приближенный поиск по умолчанию в ВПР может вернуть правдоподобное, но неверное значение без сообщения об ошибке. Номер столбца в ВПР после вставки нового столбца начинает указывать не туда.

### Неоднозначный ключ

ПРОСМОТРX – функция поиска, а не агрегирования. Если искомый код встречается в справочнике несколько раз, возвращается первое совпадение. Возможны два случая:

- ключ должен быть уникальным, значит, повтор – дефект данных;
- повторы допустимы по смыслу, значит, нужна фильтрация или агрегирование, а не поиск.

Функция не определяет, допустим ли дубликат. Это решение принимается в модели данных.

### Размерность массивов

Просматриваемый и возвращаемый массивы должны совпадать по размеру: каждой позиции в первом соответствует позиция во втором. Если возвращаемый массив состоит из нескольких столбцов, результат разворачивается как динамический массив.

### Аргумент «если не найдено»

Четвертый аргумент задает результат для единственной ситуации: совпадение не найдено.

```formula
=ПРОСМОТРX(код;коды;наименования;"не найден")
```

`ЕСЛИОШИБКА` перехватывает любые ошибки: деление на ноль, неверную ссылку, ошибку имени. Четвертый аргумент ПРОСМОТРX обрабатывает только отсутствие записи, поэтому остальные ошибки остаются видимыми.

> [!WARNING]
> Не всякое отсутствие совпадения нужно заменять нулем или пустой строкой. Если запись обязана существовать, «не найдено» – сигнал о проблеме в данных, и он должен оставаться заметным.

```quiz
question: Почему для ожидаемого отсутствия кода в справочнике предпочтительнее четвертый аргумент ПРОСМОТРX, а не ЕСЛИОШИБКА?
A: Четвертый аргумент включает приближенный поиск
B: Он обрабатывает только отсутствие совпадения и не скрывает прочие ошибки
C: Он автоматически удаляет дубликаты ключей
D: Он ускоряет поиск при любом размере данных
correct: B
explanation: Четвертый аргумент охватывает единственную ситуацию – отсутствие совпадения. Остальные ошибки формулы остаются видимыми, и их можно диагностировать. ЕСЛИОШИБКА скрывает любые ошибки.
```

## 3. Двусторонний и приближенный поиск

### Двусторонний поиск

Задача: получить значение на пересечении заданной строки и заданного столбца таблицы. Решение строится на том, что ПРОСМОТРX может вернуть массив. Внутренняя функция находит столбец по месяцу:

```formula
=ПРОСМОТРX(месяц;строка_месяцев;массив_значений)
```

Результат – столбец значений нужного месяца. Внешняя функция выбирает из него строку по точке:

```formula
=ПРОСМОТРX(
    точка;
    столбец_точек;
    ПРОСМОТРX(месяц;строка_месяцев;массив_значений)
)
```

### F9: просмотр промежуточного результата

Чтобы увидеть, что возвращает часть формулы, выделите ее в строке формул и нажмите **F9**: фрагмент заменится вычисленным значением. Для вложенной функции ПРОСМОТРX так видно весь возвращаемый столбец.

> [!WARNING]
> После просмотра нажмите **Esc**. Клавиша Enter оставит в формуле вычисленное значение вместо исходного фрагмента.

### Приближенный поиск

Если шкала задана нижними границами (например, скидка зависит от объема закупки), точного совпадения может не быть. Нужно найти точное значение или ближайшее меньшее. Для этого в пятом аргументе задается `-1`:

```formula
=ПРОСМОТРX(объем;границы;ставки;;-1)
```

Две точки с запятой подряд означают, что четвертый аргумент пропущен.

### Режим сопоставления и режим поиска

| Аргумент | Что определяет | Значения |
|---|---|---|
| Пятый: режим сопоставления | какое совпадение считать подходящим | `0` – точное; `-1` – точное или следующее меньшее; `1` – точное или следующее большее |
| Шестой: режим поиска | как выполнять поиск | `1` – с начала; `-1` – с конца; `2` – двоичный по возрастанию; `-2` – двоичный по убыванию |

Это разные параметры. Сортировка данных обязательна только для двоичного поиска (`2`, `-2`). Сочетание сопоставления `-1` с обычным поиском сортировки не требует. Для небольших шкал порогов двоичный поиск не нужен, но отсортированную шкалу легче проверять.

```quiz
question: Шкала скидок задана нижними границами объема: 0, 500 000, 1 500 000, 3 000 000. Какой пятый аргумент ПРОСМОТРX вернет скидку для объема 2 450 000?
A: 0 (точное совпадение)
B: -1 (точное или следующее меньшее)
C: 1 (точное или следующее большее)
D: 2 (двоичный поиск)
correct: B
explanation: Значения 2 450 000 в шкале нет. Нужна граница, не превышающая объем, то есть 1 500 000. Это режим -1. Режим 1 вернул бы границу 3 000 000, а режим 2 относится к порядку поиска, а не к выбору совпадения.
```

## 4. СУММПРОИЗВ и условия над массивами

СУММПРОИЗВ нужна не только для суммирования произведений: она позволяет задавать условия арифметикой над массивами, в том числе вычисляемые.

### Как работает условие

Сравнение диапазона со значением возвращает массив ИСТИНА/ЛОЖЬ. Арифметическая операция превращает ИСТИНА в 1, а ЛОЖЬ в 0. Произведение двух таких массивов равно 1 только там, где выполнены оба условия, то есть умножение дает логику «И»:

```formula
=СУММПРОИЗВ((условие1)*(условие2)*суммы)
```

Строки, не удовлетворяющие условиям, умножаются на 0 и выпадают из суммы.

Для логики «ИЛИ» массивы условий складывают. Если строка удовлетворяет обоим условиям, сумма равна 2, поэтому такой массив нужно проверять на промежуточном результате (F9).

### СУММПРОИЗВ или СУММЕСЛИМН

Для простых условий по готовым столбцам предпочтительна СУММЕСЛИМН: она короче и читается проще. СУММПРОИЗВ оправдана, если:

- условие является результатом вычисления (готового столбца с признаком нет);
- нужна арифметика над массивами;
- считается взвешенный показатель.

Расположение данных на другом листе – не повод заменять СУММЕСЛИМН на СУММПРОИЗВ.

### Вычисляемое условие

В реестре продаж нет столбца с категорией товара. Категорию можно получить по коду через справочник, применив ПРОСМОТРX сразу ко всему столбцу кодов:

```formula
=СУММПРОИЗВ(
    (Продажи!C4:C123=точка)
    *(ПРОСМОТРX(Продажи!D4:D123;Справочники!A5:A16;Справочники!C5:C16)=категория)
    *Продажи!G4:G123
)
```

Все массивы в формуле должны охватывать одни и те же строки. Ссылки на целые столбцы (миллион строк) в таких формулах замедляют пересчет.

### Средневзвешенная величина

Простое среднее цены по строкам не учитывает, что единиц продано разное количество. Верная средневзвешенная цена:

```formula
=СУММПРОИЗВ(количество;цена)/СУММ(количество)
```

> [!NOTE]
> Прежде чем агрегировать относительный показатель, нужно определить его знаменатель. Если показатель – отношение A/B, то по группе его считают как СУММ(A)/СУММ(B), а не как среднее значений A/B по строкам. Это относится к цене, марже, доходности, ставкам.

В учебной книге простое среднее цены по реестру равно 166,83 руб., а средневзвешенная цена – 165,44 руб.

```quiz
question: В каком случае СУММПРОИЗВ предпочтительнее СУММЕСЛИМН?
A: Нужно сложить один числовой столбец без условий
B: Условие является результатом вычисления, готового столбца с признаком нет
C: Данные находятся на другом листе
D: Нужно заменить любую функцию СУММ
correct: B
explanation: СУММПРОИЗВ позволяет задавать условие вычислением над массивом. Если условия заданы готовыми столбцами, СУММЕСЛИМН короче и проще. Положение данных на другом листе на выбор функции не влияет.
```

## 5. Динамические массивы

Формула с динамическим массивом возвращает не одно значение, а массив, который занимает столько ячеек, сколько нужно. Занятую область называют **областью развертывания**.

| Функция | Результат |
|---|---|
| УНИК | уникальные значения |
| ФИЛЬТР | строки, удовлетворяющие условию |
| СОРТ, СОРТПО | упорядоченный массив |
| ПОСЛЕД | последовательность чисел |
| СЛУЧМАССИВ | массив случайных чисел |

Например, `=УНИК(диапазон)` записывается в одну ячейку, а результат занимает несколько. Формула хранится только в первой ячейке, остальные ячейки области отдельно не редактируются.

### Таблица на входе, массив на выходе

Исходные данные хранят в структурированной таблице: она сама расширяет входной диапазон. Формулу с динамическим массивом размещают вне таблицы. Структура: таблица расширяет вход, динамическая формула расширяет результат, зависимые формулы ссылаются на всю область результата.

### Оператор `#`

Если динамическая формула начинается в ячейке F5, то запись `F5#` означает всю область развертывания независимо от ее размера:

```formula
=СУММ(F5#)
=ЧСТРОК(F5#)
```

При увеличении массива ссылка расширится сама.

> [!WARNING]
> Не ссылайтесь на динамический результат фиксированным диапазоном «с запасом» (`F5:F20`). Такая ссылка снова привязывает модель к текущему размеру.

### Ошибка #ПЕРЕНОС!

Если хотя бы одна ячейка будущей области развертывания занята, массив не строится, и Excel возвращает `#ПЕРЕНОС!`. Достаточно освободить занятую ячейку.

### Несколько условий в ФИЛЬТР

Условия объединяют умножением:

```formula
=ФИЛЬТР(диапазон;(условие1)*(условие2);"нет строк")
```

Функция `И` не подходит: она сворачивает массив в одно значение. Третий аргумент ФИЛЬТР, как и четвертый аргумент ПРОСМОТРX, используют осознанно: если отсутствие строк допустимо, выводят сообщение; если оно сигнализирует о дефекте данных, его нейтральным текстом не маскируют.

```quiz
question: Формула `=УНИК(Справочники!C5:C16)` записана в J5 и возвращает 4 значения. Какая запись считает их количество и останется верной при росте списка?
A: `=ЧСТРОК(J5:J8)`
B: `=ЧСТРОК(J5#)`
C: `=ЧСТРОК(J5)`
D: `=СУММ(J5#)`
correct: B
explanation: Оператор # охватывает всю область развертывания и расширяется вместе с ней. Диапазон J5:J8 привязан к текущему размеру. Ссылка J5 дает одну ячейку, а СУММ складывает значения, а не считает строки.
```

## 6. Функция LET

LET объявляет внутри формулы именованные промежуточные величины:

```formula
=LET(
    имя1;значение1;
    имя2;значение2;
    выражение_результата
)
```

LET решает две задачи.

**Читаемость.** Повторяющееся выражение вычисляется один раз, получает содержательное имя и используется по имени. В отличие от имен диспетчера имен, переменные LET существуют только внутри своей формулы и не засоряют список имен книги. Переменной может быть значение, диапазон или массив.

**Меньше повторных вычислений.** Если сложное выражение встречается в формуле трижды, Excel вычисляет его три раза. Если оно объявлено как переменная LET, то вычисляется один раз. Это важно для больших массивов, повторных ПРОСМОТРX и ФИЛЬТР.

Пример для средневзвешенной цены:

```formula
=LET(
    выручка;СУММПРОИЗВ(Продажи!E4:E123;Продажи!F4:F123);
    количество;СУММ(Продажи!E4:E123);
    выручка/количество
)
```

LET нужна, если выражение длинное или дорогое и повторяется, или если формула состоит из нескольких содержательных шагов, которым полезно дать имена. Короткую формулу в один шаг оборачивать в LET не нужно.

> [!NOTE]
> Функция LAMBDA развивает идею LET и позволяет создавать собственные функции. В программу курса она не входит и в Excel 2021 недоступна.

## 7. Разбор формулы с помощью языковой модели

Языковая модель может помочь прочитать чужую формулу и подготовить черновой вариант упрощения.

```
Ниже формула Excel:

[ВСТАВЬТЕ ФОРМУЛУ]

1. Опиши вычисление по этапам.
2. Перечисли зависимости формулы.
3. Найди повторяющиеся выражения.
4. Найди числовые константы и укажи, чем они являются: изменяемыми предпосылками или величинами, вытекающими из определения показателя.
5. Предложи эквивалентную запись через LET, если она улучшает читаемость или убирает повторные вычисления.
6. Не меняй диапазоны, условия и знаки операций.
7. Отдельно перечисли, что нужно проверить в Excel после преобразования.
```

Новую формулу нельзя считать эквивалентной без проверки. Порядок проверки:

1. сравнить результаты старой и новой формулы на исходных данных;
2. изменить несколько входных значений;
3. убедиться, что результаты по-прежнему совпадают;
4. отдельно проверить диапазоны, знаки операций и условия.

## 8. Модель вычислений и волатильные функции

На стоимость пересчета влияет не только результат формулы, но и ее устройство.

### Граф зависимостей

Excel не пересчитывает всю книгу при каждом изменении. Он строит граф зависимостей между ячейками и после изменения значения пересчитывает только формулы, которые зависят от него напрямую или через цепочку других формул.

### Режим вычислений

Режим выбирается в «Формулы» → «Параметры вычислений». В автоматическом режиме формулы пересчитываются сразу после изменения данных. В ручном режиме данные уже изменены, а на экране остаются прежние результаты.

| Клавиши | Действие |
|---|---|
| F9 | пересчитать измененные формулы и зависящие от них во всех открытых книгах |
| Shift+F9 | пересчитать активный лист |
| Ctrl+Alt+F9 | полный пересчет всех формул независимо от признака изменения |

> [!WARNING]
> Режим вычислений действует на все открытые книги. После опыта с ручным режимом верните «Автоматически», иначе вы можете работать с устаревшими значениями.

### Волатильные функции

Волатильные функции пересчитываются при каждом пересчете книги, даже если их аргументы не менялись. К ним относятся СЛЧИС, СЛУЧМЕЖДУ, СЕГОДНЯ, ТДАТА, СМЕЩ, ДВССЫЛ, а также ЯЧЕЙКА и ИНФОРМ в ряде режимов. Вместе с волатильной ячейкой пересчитываются все формулы, которые от нее зависят.

Поэтому важно не только наличие волатильной функции, но и ее положение в графе зависимостей. Одна функция СЕГОДНЯ в заголовке практически не влияет на скорость. Большое число функций СМЕЩ в основе расчетной модели замедляет всю ветвь зависимых формул.

### Что показывают опыты листа «Пересчет»

**Опыт 1. СЛЧИС.** Изменение ячейки B6 меняет значение B7 (СЛЧИС), хотя B7 от B6 не зависит. Это признак волатильности.

**Опыт 2. СМЕЩ и прямая ссылка.** Суммы в B13 (через СМЕЩ) и B14 (через прямой диапазон) равны, но B13 пересчитывается при каждом пересчете, а B14 – только при изменении реестра. Динамический диапазон лучше задавать структурированной таблицей: зависимость остается явной, а волатильная функция не нужна.

**Опыт 3. ДВССЫЛ.** Функция получает адрес в виде текста. Трассировка влияющих ячеек такую связь не показывает, поэтому ДВССЫЛ ухудшает проверяемость книги (см. занятие 1.1).

> [!NOTE]
> Волатильная функция допустима, если без нее задача не решается и нет более прозрачного решения. В этом случае причина и стоимость применения должны быть понятны.

### Диагностика медленной книги

1. Определить режим вычислений.
2. Найти волатильные функции.
3. Оценить положение каждой в графе зависимостей.
4. Найти повторяющиеся дорогие выражения.
5. Только после этого менять формулы.

```quiz
question: Почему одна волатильная функция может иметь разную стоимость в разных местах книги?
A: Excel случайно выбирает время ее пересчета
B: Стоимость зависит от числа формул, зависящих от нее, которые тоже пересчитываются
C: Любая волатильная функция всегда пересчитывает всю книгу
D: Волатильность влияет только на размер файла
correct: B
explanation: Волатильная функция пересчитывается при каждом пересчете, а вместе с ней пересчитывается вся цепочка зависимых формул. Поэтому важно, сколько формул находится ниже нее в графе зависимостей.
```

## 9. Итоги занятия

1. ПРОСМОТРX по умолчанию ищет точное совпадение и принимает независимые массивы поиска и возврата.
2. Ожидаемое отсутствие совпадения обрабатывается четвертым аргументом ПРОСМОТРX, а не скрывается через ЕСЛИОШИБКА.
3. Режим сопоставления и режим поиска – разные параметры. Сортировка обязательна только для двоичного поиска.
4. СУММПРОИЗВ нужна, когда условие получено вычислением или требуется арифметика над массивами; для простых условий используют СУММЕСЛИМН.
5. Средневзвешенная величина не равна простому среднему.
6. Формулу с динамическим массивом размещают вне структурированной таблицы, а на ее результат ссылаются оператором `#`.
7. LET дает имена промежуточным величинам и убирает повторные вычисления внутри формулы.
8. В ручном режиме вычислений на экране остаются устаревшие результаты; для диагностики служат F9, Shift+F9 и Ctrl+Alt+F9.
9. Волатильные функции пересчитываются при каждом пересчете и тянут за собой зависимые формулы; риск определяется размером этой цепочки.
