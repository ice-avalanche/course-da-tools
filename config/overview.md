Учебник сопровождает курс «Инструменты для анализа финансовых данных I»: девять учебных дней по два занятия. Каждое занятие состоит из теории с примерами, коротких вопросов для самопроверки и практического задания, которое выполняется на учебной рабочей книге.

### Как работать с учебником

1. Читайте занятие по порядку и отвечайте на вопросы после разделов. Неверный ответ не раскрывает правильный вариант: вернитесь к тексту.
2. Файлы к занятию скачивайте по ссылке в начале задания и выполняйте шаги по порядку. В каждой части даны контрольные числа, по которым можно проверить себя.
3. Если шаг не получается, не пропускайте его молча: запишите, где остановились, и вернитесь к соответствующему разделу.

### Требования

Microsoft Excel 2021 или Microsoft 365 под Windows. Названия команд приведены по русскому интерфейсу.
