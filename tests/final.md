# Итоговый тест: дни 6–9

## День 6. Статистика и прогнозирование

```quiz
question: Почему качество прогнозной модели нельзя оценивать на тех же данных, на которых она строилась?
A: Потому что на истории модель всегда дает нулевую ошибку
B: Потому что Excel не позволяет считать ошибку на истории
C: Потому что история всегда содержит выбросы
D: Потому что хорошее совпадение с историей показывает лишь описание уже виденных данных, а не способность прогнозировать
correct: D
explanation: Для проверки прогноза нужен holdout: период, который модель не видела. Совпадение с обучающей выборкой не доказывает качества на будущем.
```

```quiz
question: Для какого случая MAPE ненадежна?
A: Когда фактические значения близки к нулю
B: Когда ряд имеет тренд
C: Когда ряд имеет сезонность
D: Когда горизонт прогноза превышает год
correct: A
explanation: MAPE делит ошибку на факт; при значениях около нуля процентная ошибка становится очень большой и нестабильной.
```

```quiz
question: Что такое rolling backtest?
A: Прогноз на один период вперед по всей истории
B: Подбор параметров ETS по минимуму ошибки на истории
C: Сглаживание ряда скользящим средним
D: Повторная проверка модели в нескольких origin с оценкой на следующих периодах
correct: D
explanation: Rolling backtest строит модель по истории до каждого origin и оценивает прогноз на следующих периодах; это дает оценку по горизонтам.
```

```quiz
question: Что показывает рабочий горизонт?
A: Максимальную дальность, на которой backtest подтверждает приемлемое качество по заранее заданному критерию
B: Максимальную дальность прогноза, которую позволяет построить Excel
C: Число периодов в обучающей выборке
D: Период, за который ряд полностью обновляется
correct: A
explanation: Рабочий горизонт определяется по результатам backtest и заданному критерию качества, а технический горизонт лишь описывает возможности функции.
```

## День 7. Автоматизация на VBA

```quiz
question: Зачем в макросе определяют последнюю заполненную строку, а не записывают номер строки в код?
A: Код продолжает работать при изменении числа строк в данных
B: Это ускоряет открытие книги
C: Это защищает книгу от изменений
D: Это требуется синтаксисом VBA
correct: A
explanation: Фиксированный номер строки перестает соответствовать данным после их роста или сокращения. Расчет последней строки делает код устойчивым.
```

```quiz
question: Почему параметры расчета (например, порог отклонения) выносят в ячейки листа, а не в код макроса?
A: Чтобы макрос работал быстрее
B: Чтобы изменять правило без правки кода и сохранить прозрачность модели
C: Чтобы макрос можно было запускать без включения макросов
D: Потому что VBA не поддерживает константы
correct: B
explanation: Параметры в ячейках изменяются пользователем без обращения к коду и видны в модели. Значения в коде скрыты и требуют правки процедуры.
```

```quiz
question: Для чего ведется журнал выполнения автоматизации?
A: Для увеличения скорости обработки
B: Для замены контрольных сумм
C: Для защиты кода паролем
D: Для фиксации того, что обработано и какие ошибки возникли, чтобы результат можно было проверить
correct: D
explanation: Журнал записывает обработанные объекты, время и ошибки; без него невозможно установить, что именно сделал макрос и где он остановился.
```

```quiz
question: При пакетной обработке файлов один файл содержит ошибку формата. Какое поведение корректно?
A: Записать ошибку в журнал, пропустить файл и продолжить обработку остальных
B: Остановить всю обработку без сообщения
C: Заменить ошибочные значения нулями
D: Удалить файл из папки
correct: A
explanation: Обработка должна быть устойчивой: ошибка фиксируется, остальные файлы обрабатываются, итог показывает, какие файлы не вошли в расчет.
```

## День 8. Дашборды и BI

```quiz
question: Что является основным требованием к управленческому дашборду?
A: Максимальное число диаграмм на одном экране
B: Использование только круговых диаграмм
C: Отсутствие фильтров
D: Ответ на заранее определенные управленческие вопросы с контрольными числами, сверенными с моделью
correct: D
explanation: Дашборд строится от вопросов пользователя, а его показатели сверяются с расчетной моделью. Число визуальных элементов не является целью.
```

```quiz
question: Почему доля или процентный показатель не должен суммироваться по группам?
A: Потому что Excel не суммирует проценты
B: Потому что проценты нельзя фильтровать
C: Потому что сумма долей групп не равна доле итога; показатель нужно пересчитывать из числителя и знаменателя
D: Потому что проценты хранятся как текст
correct: C
explanation: Отношение в итоге равно отношению сумм, а не сумме отношений. В BI показатель задается формулой агрегации числителя и знаменателя.
```

```quiz
question: Что необходимо выполнить при переносе модели из Excel в BI-систему?
A: Ничего: результаты совпадут автоматически
B: Удалить все вычисляемые показатели
C: Заменить все диаграммы таблицами
D: Приемку: сравнить значения BI и Excel в нескольких контекстах фильтров
correct: D
explanation: Различия в агрегации, типах и фильтрах приводят к расхождениям. Приемка по нескольким контекстам выявляет их до использования дашборда.
```

```quiz
question: Какова основная роль слоя данных (датасета) в BI?
A: Оформление дашборда
B: Рассылка отчетов
C: Единое определение полей и показателей для всех чартов
D: Хранение паролей пользователей
correct: C
explanation: Датасет содержит типы, роли полей и показатели; чарты используют их повторно, поэтому определение показателя не копируется в каждый отчет.
```

## День 9. Оптимизация и Monte Carlo

```quiz
question: Решена линейная задача симплекс-методом. Теневая цена ограничения равна 0. Что это означает?
A: Ограничение нарушено
B: Ограничение не является активным: увеличение лимита не повысит цель
C: Задача не имеет решения
D: Решение найдено неверно
correct: B
explanation: Нулевая теневая цена означает, что ограничение не сужает оптимум; ресурс использован не полностью.
```

```quiz
question: В задаче выбора проектов жадное правило по индексу рентабельности дало NPV 44,5, а Solver с бинарными переменными – 47,1. Как объясняется разница?
A: Solver ошибается из-за округления
B: Бинарные переменные допускают доли проектов
C: Жадное правило не учитывает остаток бюджета и не гарантирует оптимума
D: Индекс рентабельности рассчитан неверно
correct: C
explanation: Правило выбирает проекты по очереди и не анализирует сочетания; точное решение перебирает допустимые наборы и учитывает использование всего бюджета.
```

```quiz
question: Какое значение целевой функции в задаче с долями проектов (0 ≤ x ≤ 1) по сравнению с бинарной задачей?
A: Меньше или равно
B: Больше или равно
C: Всегда равно
D: Не сравнивается
correct: B
explanation: Допустимое множество релаксации шире, поэтому максимум не меньше. Значение релаксации служит верхней границей целочисленного оптимума.
```

```quiz
question: Симуляция Monte Carlo построена на формулах с СЛЧИС(). Что нужно сделать, чтобы результаты можно было проверить и воспроизвести?
A: Ничего: СЛЧИС() дает одинаковые числа
B: Увеличить число формул СЛЧИС() в два раза
C: Зафиксировать случайные числа значениями и указать число итераций
D: Пересчитать книгу вручную через F9 до совпадения
correct: C
explanation: СЛЧИС() меняется при каждом пересчете. Сохраненные значения U(0;1) делают результат воспроизводимым и проверяемым.
```

## Сквозные вопросы

```quiz
question: Модель, построенная в Excel, выдает правдоподобные числа. Какое действие наиболее надежно подтверждает ее корректность?
A: Оформление листов по единому стилю
B: Контрольные значения, воспроизводимые независимым расчетом
C: Защита листов паролем
D: Отсутствие сообщений об ошибках
correct: B
explanation: Правдоподобие и отсутствие ошибок не гарантируют верности. Независимый расчет контрольных значений выявляет молчаливые ошибки.
```

```quiz
question: Какой инструмент подходит для вопроса «при каком значении цены NPV станет равен нулю»?
A: Монте-Карло с 1000 итераций
B: Круговая диаграмма
C: Поиск критического значения (подбор параметра)
D: Сводная таблица
correct: C
explanation: Критическое значение находится решением уравнения NPV(цена) = 0, например подбором параметра. Симуляция оценивает распределение, а не конкретную точку.
```

```quiz
question: Какой вопрос лучше всего решается оптимизацией, а не сценарным анализом?
A: Какой будет NPV при падении цены на 10 %?
B: Какие значения управляемых переменных дают максимальную цель при ограничениях?
C: Как изменится прибыль при росте ставки?
D: Какова вероятность убытка?
correct: B
explanation: Оптимизация подбирает управляемые переменные при ограничениях. Остальные вопросы описывают последствия заданных значений или вероятность событий.
```

```quiz
question: Какой набор методов отвечает на вопрос «какова вероятность убытка проекта при заданных распределениях входов»?
A: Монте-Карло с распределениями входов
B: Анализ чувствительности по одному фактору
C: Сценарии «базовый, оптимистичный, пессимистичный»
D: Оптимизация Solver
correct: A
explanation: Вероятность события определяется по распределению результата, которое дает симуляция. Чувствительность и сценарии вероятностей не оценивают.
```
