# Промежуточный тест: дни 1–5

## День 1. Архитектура книги и формулы: вопрос 1

```quiz
question: Что такое молчаливая ошибка?
A: Ошибка, при которой Excel выводит #ЗНАЧ!, но книга продолжает работать
B: Неверный результат, при котором Excel не выводит сообщения об ошибке
C: Ошибка в формуле, скрытая функцией ЕСЛИОШИБКА по умолчанию
D: Ошибка, возникающая только при пересчете в режиме «Вручную»
correct: B
explanation: Молчаливая ошибка не сопровождается сообщением: формула вычисляется, но результат неверен. Поэтому нужны контрольные суммы и диагностика (занятие 1.1).
```

## День 1. Архитектура книги и формулы: вопрос 2

```quiz
question: В формуле налога записано `=B5*0,2`. Как следует поступить по правилу об изменяемых числах?
A: Оставить как есть: константа 0,2 понятна из контекста
B: Заменить на значение, записанное в ячейке слоя предпосылок, и сослаться на нее по имени или адресу
C: Заменить 0,2 на 20 %: так формула станет читаемее
D: Скрыть столбец с формулой, чтобы значение не изменили случайно
correct: B
explanation: Изменяемая величина записывается в одной ячейке предпосылок. При изменении ставки правится одна ячейка, а не каждая формула.
```

## День 1. Архитектура книги и формулы: вопрос 3

```quiz
question: Как правильно рассчитать средневзвешенную цену по строкам, если веса находятся в диапазоне B2:B10, а цены в C2:C10?
A: =СРЗНАЧ(C2:C10)
B: =СУММПРОИЗВ(B2:B10;C2:C10)/СУММ(B2:B10)
C: =СУММ(B2:B10*C2:C10)
D: =СУММПРОИЗВ(B2:B10;C2:C10)/СЧЁТ(C2:C10)
correct: B
explanation: Сумма произведений весов на значения делится на сумму весов. Простое среднее игнорирует веса, деление на число строк не нормирует их.
```

## День 2. Power Query: вопрос 1

```quiz
question: Почему отмену свертывания (unpivot) выполняют по варианту «Отменить свертывание других столбцов»?
A: Так формируется меньше строк
B: При появлении нового месяца новый столбец автоматически попадает в данные без правки запроса
C: Этот вариант быстрее для источников из папки
D: Другие варианты не поддерживают тип «Текст»
correct: B
explanation: Выбор столбцов с названиями месяцев закрепляет их в запросе. Вариант «других столбцов» фиксирует только неизменяемые столбцы, остальные становятся строками.
```

## День 2. Power Query: вопрос 2

```quiz
question: В столбце «Сумма» источник содержит заполнители «н/д» и «-». Во что их следует преобразовать?
A: В ноль: данных нет, значит значение нулевое
B: В null: отсутствующее значение не участвует в подсчете количества и среднего
C: В пустую строку, оставив столбец текстовым
D: Удалить строки с такими значениями
correct: B
explanation: Ноль искажает среднее и количество, а удаление строк меняет число записей. Отсутствие данных кодируется null.
```

## День 2. Power Query: вопрос 3

```quiz
question: Фактические продажи по точкам и месяцам объединяются с планом. Прямое слияние с транзакциями дублирует план. Что делать?
A: Использовать внутреннее соединение вместо левого внешнего
B: Сначала сгруппировать факт до уровня «точка × месяц», затем слить с планом по двум ключам
C: Удалить дубликаты в плане после слияния
D: Заменить слияние добавлением запросов
correct: B
explanation: План имеет гранулярность «точка × месяц», транзакции мельче. Перед слиянием уровни детализации выравнивают, иначе значение плана повторяется для каждой транзакции.
```

## День 3. Модель данных и DAX: вопрос 1

```quiz
question: Почему плоская таблица может давать верный общий итог и неверный разрез по регионам?
A: Итог в плоской таблице всегда завышен
B: Атрибут региона хранится в каждой строке факта и может расходиться для одной точки; разрез строится по ошибочным значениям
C: Сводная таблица не умеет группировать текстовые поля
D: Региональные итоги не суммируются в общий
correct: B
explanation: В плоской таблице атрибуты повторены в каждой строке, поэтому одна точка может оказаться в двух регионах. В модели данных регион хранится один раз в справочнике.
```

## День 3. Модель данных и DAX: вопрос 2

```quiz
question: Каким условием определяется связь «один ко многим» между справочником точек и таблицей фактов?
A: Код точки в справочнике уникален, в таблице фактов повторяется
B: Код точки уникален в обеих таблицах
C: Код точки может повторяться в справочнике, но не в таблице фактов
D: Обе таблицы содержат одинаковое число строк
correct: A
explanation: На стороне «один» (справочник) ключ уникален, на стороне «многие» (факты) повторяется. Дубликат в справочнике делает связь невозможной.
```

## День 3. Модель данных и DAX: вопрос 3

```quiz
question: Как корректно вычислить среднюю цену в мере DAX, если в таблице есть выручка и количество?
A: AVERAGE(FactSales[Цена строки])
B: DIVIDE(SUM(FactSales[Выручка]); SUM(FactSales[Количество]))
C: SUM(FactSales[Цена строки]) / COUNTROWS(FactSales)
D: MAX(FactSales[Цена строки])
correct: B
explanation: Средняя цена – отношение суммарной выручки к суммарному количеству. Среднее из средних цен строк игнорирует различие весов и завышает результат.
```

## День 4. Чувствительность: вопрос 1

```quiz
question: Значения цены записаны в столбце по вертикали. Какое поле диалога «Таблица данных» заполняется для однофакторной таблицы?
A: «Подставлять значения по строкам в»
B: «Подставлять значения по столбцам в»
C: Оба поля
D: Ни одно: Excel определяет ячейку автоматически
correct: B
explanation: Поле выбирается по расположению списка тестовых значений: вертикальный список – по столбцам.
```

## День 4. Чувствительность: вопрос 2

```quiz
question: Эластичность NPV по цене равна 7,35. Как это читать?
A: Около базовой точки рост цены на 1 % изменяет NPV примерно на 7,35 % при прочих равных
B: Рост цены на 7,35 руб. увеличивает NPV на 1 млн руб.
C: Вероятность роста NPV равна 7,35 %
D: NPV в 7,35 раза превышает выручку
correct: A
explanation: Эластичность – отношение относительных изменений результата и предпосылки. Это локальная характеристика, а не вероятность.
```

## День 4. Чувствительность: вопрос 3

```quiz
question: Что обязательно выполняется после «Подбора параметра» на модели?
A: Ничего: результат сохраняется для следующих расчетов
B: Найденное значение записывается отдельно, предпосылка возвращается к базе, проверяется базовый NPV
C: Модель закрывается без сохранения
D: Подбор повторяется до совпадения с целью
correct: B
explanation: Подбор параметра записывает найденное значение во входную ячейку и тем самым меняет модель. Без возврата к базе следующие расчеты выполняются на искаженной точке.
```

## День 5. Сценарии и стресс-тесты: вопрос 1

```quiz
question: Чем сценарий отличается от однофакторной чувствительности?
A: Сценарий задает вероятность каждого исхода
B: Сценарий меняет согласованный набор предпосылок, чувствительность – одну при неизменных остальных
C: Сценарий применяется только к затратам
D: Сценарий строится только с помощью таблицы данных
correct: B
explanation: Различие в постановке: сценарий описывает целостное состояние, где предпосылки связаны общей причиной. Вероятность сценарию не приписывается.
```

## День 5. Сценарии и стресс-тесты: вопрос 2

```quiz
question: После переключения сценария выручка 2024 года изменилась. Что это означает?
A: Так и должно быть: сценарий меняет всю шкалу времени
B: Фактический слой подключен к сценарным предпосылкам ошибочно
C: Изменилась ставка дисконтирования
D: Нужно обновить список проверки данных
correct: B
explanation: Исторические данные не зависят от предположений о будущем. Неизменность факта – основной инвариант сценарной модели.
```

## День 5. Сценарии и стресс-тесты: вопрос 3

```quiz
question: Для NPV = 0 критический коэффициент интенсивности k равен 47,5 %. Какая формулировка корректна?
A: Вероятность отрицательного NPV составляет 47,5 %
B: При прохождении 47,5 % пути от базы к полному стрессу NPV пересекает ноль при заданном стресс-векторе
C: Модель выдерживает любой стресс до 47,5 % по всем KPI
D: В 47,5 % случаев NPV окажется ниже нуля
correct: B
explanation: Коэффициент k – индекс интенсивности заданного вектора, а не вероятность. Он определен только вместе с KPI и порогом.
```
